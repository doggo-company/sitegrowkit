初めて使うときは

Docker Desktopを起動してから、サイトを作成してください。Node.jsのインストールやコマンド入力は不要です。

WindowsではWSL2とUbuntu 24.04、DockerのWSL Integrationが必要です。セットアップ画面で環境を確認できます。

作成済みフォルダには実行されるプログラムが含まれます。自分で作成したもの、または信頼できる相手から受け取ったものを追加してください。

処理の詳細


公開前の確認
内容確認は10分間有効です。公開時にファイルを再作成します。作業中の編集は保存してから確認し、公開が終わるまで編集を止めてください。


操作履歴
    旧版へ切り戻す
    前回のプログラムに戻します。データベース・記事・画像は以前の状態に戻りません。DB変更との互換性を確認してください。
    

    

    ブラウザやこのアプリを閉じてもサイトは動き続けます。止めるときは対象サイトの「停止」を押してください。記事や画像は残ります。
