# SiteGrowKit — ボタンで始める

1. Docker Desktopを起動します。
2. Macは `SiteGrowKit.app`、Windowsは `SiteGrowKit.exe` をダブルクリックします。
3. 初回はブラウザにWelcome画面が開きます。「はじめる」から環境を確認します。
4. 「新しいサイトをつくる」または「作成済みのサイトを追加」を選びます。

案内を終えた後は、次回からサイト一覧が直接開きます。「あとで設定する サイト一覧へ」でも進めます。
案内を見直すときは、サイト一覧右上の「はじめ方」を押してください。
Dockerなどの準備が必要な場合は確認画面の案内に沿って準備し、「もう一度確認」を押します。

MacでDMGを開いた段階ではインストール用のウィンドウが表示されます。Welcome画面はアプリを開くと表示されます。
WindowsはWSL2・Ubuntuの初回設定後、起動準備の表示に続いてWelcome画面が開きます。

コマンド入力やNode.jsの別途インストールは不要です。
詳しい手順は同じフォルダの **README_FIRST.html** をブラウザで開いてください。

Mac版はDMGを開き、SiteGrowKit.appをApplicationsへドラッグしてから開きます。ZIP版も利用できます。
Windowsではフォルダ全体を一緒に保存してください。exeだけを移動せず、ショートカットを使います。
Windowsの初回環境にはWSL2・Ubuntu 24.04・Docker DesktopのWSL Integrationが必要です。

次回からもアプリを開き、サイト一覧の「起動」「管理画面を開く」「停止」で操作します。
別の場所に作成したサイトは「フォルダから追加」で登録できます。
自分のサイト、または信頼できる相手から受け取ったフォルダだけを追加してください。
「セットアップを終了して一覧に戻る」で、他のサイトの起動・停止へ戻れます。

ブラウザやアプリを閉じるだけではサイトは停止しません。「停止」で対象サイトを止めます。
記事・画像・データは残ります。処理に失敗したときは、画面の確認コードを添えてご連絡ください。
パスワードや.envの内容は送らないでください。

本体は0.9.4-rc5です。Mac向けの署名・公証版はDesktop 2.6、Windows版はDesktop 2.6です。
Mac版 Desktop 2.6はDOGGO COMPANY K.KのDeveloper IDで署名し、Appleの公証を受けています。公証チケットをアプリとDMGに添付しています。旧Mac版や独自ビルドはこの公証の対象ではありません。Windows版の発行者署名は未実施です。

## ログイン情報が分からないとき

1. サイト一覧で対象のローカルサイトを起動します。
2. 「ログイン情報・再設定」を押し、管理者のメールアドレスを確認します。
3. 初期パスワードが現在も有効なら、伏せ字の欄から「表示」「コピー」ができます。
4. 初期情報がない・変更済みの場合は管理者を選び、確認にチェックを付けて「再設定画面を開く」を押します。
5. 開いたタブで新しいパスワードを設定し、管理画面へログインします。メールの受信は不要です。

ローカルサイト専用です。再設定リンクは表示された有効時間内に1回だけ使えます。
記事・画像・権限は変わりません。二段階認証は解除されず、認証コードまたはリカバリーコードが引き続き必要です。
画面内のログイン情報は60秒後、または画面を閉じると消えます。コピーした内容はクリップボードに残ります。
ボタンがない場合は、Desktop 2.6を開き直してください。

## ステージング・本番の管理

1. 左の一覧から対象サイトを選びます。
2. 「ステージング」または「本番」を選び、「公開先の接続設定」を入力して保存します。
3. 「接続を確認」でサーバーの不足項目を確認します。
4. 「公開内容を確認」で公開用ファイルの作成と接続先・DB変更の確認を行います。
5. 表示された環境・URL・配置先・変更内容を確認し、チェックを付けて公開します。
6. 実行中は工程と経過時間、完了後は確認結果と操作履歴が表示されます。

初期対応はXserverです。ドメイン・SSL・DB・SSH公開鍵・サーバー側 shared/.env の初期設定は別途必要です。未設定の項目は接続確認に表示されます。このGUIは契約やサーバー初期設定を自動代行しません。MacはMac側、WindowsはUbuntu側のSSH設定・鍵・既知のホスト情報を使用します。SSH接続先の本人確認や秘密鍵のパスフレーズ入力をGUIで行う機能はまだありません。

公開時は選んだサイトのローカルファイルを対象環境へ送ります。ステージングで変更したDBを本番へコピーする機能はありません。記事・画像は環境ごとに管理します。

「旧版へ切り戻す」はプログラムの旧版への切替です。DB・記事・画像を元に戻す操作ではありません。公開前にDBバックアップが成功しない場合は公開を停止します。初回公開には旧版がないため、自動切り戻し先もありません。

公開内容の確認は10分間・1回だけ有効です。接続先・ソース・サーバーの公開版が変わった場合は確認し直します。公開処理中にソースを編集しないでください。別アプリから同じサイトへ同時に公開する操作はロックされます。

実際の公開には対象サーバーへのアクセスが必要です。GUI実装の検証と、お客様のサーバーへの公開実績は別です。配布物の検証範囲は docs/release-20260909/desktop2-guide.md を参照してください。
